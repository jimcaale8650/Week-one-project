The .NET Ecosystem & Execution Flow
C# Language: A modern, strongly-typed, object-oriented programming language created by Microsoft.

CLR (Common Language Runtime): The execution engine that manages code execution, memory management (garbage collection), and security checks.

CIL & JIT Compilation: C# code is first compiled into CIL (Common Intermediate Language). The JIT (Just-In-Time) Compiler inside the CLR then translates CIL into native machine code at runtime.
